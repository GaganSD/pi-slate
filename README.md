# pi-extensions

Public Pi packages. First package: **pi-minimal-ui**.

A quiet, translucent interface with:

- Header, footer, and composer
- Right-hand sidebar: Files Changed, Plan, Preview, Context
- Image peek: paste a clipboard image → `[image-N]`; caret on the token previews it
- Theme `pi-minimal`

## Install

```bash
pi install git:github.com/GaganSD/pi-extensions
```

Then set `"theme": "pi-minimal"` if you want the bundled theme. Run `/minimal-ui` for density and footer.

Do not also install a second sidebar or a local copy of this UI.
